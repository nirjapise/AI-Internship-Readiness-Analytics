# 📊 AI Internship Readiness Analytics Dashboard

## 📖 Project Overview

The **AI Internship Readiness Analytics Dashboard** is an end-to-end Microsoft Excel data analytics project developed to evaluate the internship readiness of students based on their technical skills, academic performance, communication skills, resume quality, LinkedIn profile, and project experience.

This project demonstrates the complete data analytics workflow, including data cleaning, feature engineering, business analysis, dashboard development, and insight generation using Microsoft Excel.

---

# 🎯 Project Objectives

- Evaluate internship readiness using multiple performance indicators.
- Clean and validate raw data for analysis.
- Calculate internship readiness scores using weighted metrics.
- Identify skill gaps among students.
- Analyse internship trends using Pivot Tables.
- Build an interactive dashboard to support data-driven decision-making.
- Generate meaningful business insights and recommendations.

# 🔍 Key Insights

The project helped identify important trends in student internship readiness.

Some of the major insights include:

- Students with higher readiness scores were more likely to secure internships.
- Strong technical skills positively influenced internship outcomes.
- Resume quality and LinkedIn profiles contributed to overall readiness.
- Skill gap analysis highlighted areas requiring additional training.
- Readiness scores varied across colleges and degree programs.
